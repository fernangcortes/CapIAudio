# Task File: Criação Literária & Roteiro (✍️) Module

This task list addresses character profiling, outline building, and narrative flow tracking.

## 🛠️ Objectives
- Map story plotting markers (Plot Twist, Quest/World, Persona Entry, Logical Hole, Note).
- Implement narrative structure planners.
- Support scene-by-scene script outlines.

---

## 📋 Task Details

### Task LITERARY-1: Writer Setup & Metadata
- **Objective:** Configure story tracking fields: Story/Project, Active Chapter, Target Word Count, Genre.
- **Buttons Configured:** Hero/Vilão (Abre modal de ficha), Universo/Local, Plot Twist, Furo/Inconsistência, Nota Rápida.

### Task LITERARY-2: Plot Engine AI Prompt Model
- **Objective:** Create domain prompts guiding Gemini to index plot structures, character motivations, script dialogues, and logical continuity checks.
- **Verification:** Ensure plot twists are linked directly to markers.

### Task LITERARY-3: Outline Exporter
- **Objective:** Format markers directly into standard stage directions and dialogue outlines matching screenplay standards (Celtx/Final Draft templates).
